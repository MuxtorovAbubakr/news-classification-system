# News Classification System

## Overview

This project aims to classify news articles into four categories using machine learning and a Feedforward Neural Network (FFNN).

The project will use the AG News dataset.

## Objectives

- Explore and understand the news dataset.
- Build a Logistic Regression baseline.
- Develop a Feedforward Neural Network for text classification.
- Evaluate and compare the models.
- Build a reusable prediction pipeline.

## Technologies

- Python
- NumPy
- pandas
- scikit-learn
- TensorFlow or PyTorch
- Jupyter Notebook
- Git and GitHub
